# Food and drink guide proposal

Keep /menu as the primary menu and price reference. Add /food-drinks as a visual discovery page once the venue approves its content. ## Page structure

1. Short introduction with authentic food/drink photography and a clear “Xem thực đơn” action.
2. Category navigation: drinks, starters/salads, main dishes, rice/pasta and sharing snacks. The final categories should match approved items, not blindly inherit the old hierarchy.
3. Small featured selection, followed by filterable cards. Each card has a verified name, image and short factual description. Tags such as vegetarian/spicy/allergens require venue confirmation; do not infer them from a photo.
4. A card can open a compact detail panel with more images and useful context. Link to the relevant /menu?page=N category when the item is actually present in the current book. Items absent from the book need explicit venue approval before publication.
5. Booking action using the existing dialog. No cart, stock claims or ordering workflow is implied.

Do not repeat stale morning/evening prices from the old catalog. Either keep prices in the flipbook only, or later give both views a clearly maintained common data source. Avoid public migration disclaimers and “old catalog” labels; verify content before showing it.

## Navigation and scope

The primary menu link continues to open the flipbook. A secondary “Món ăn & đồ uống” link can lead to the guide. Avoid recreating every old category as a thin standalone page. Add individual dish URLs only when there is enough unique, maintained content to justify them.

If staff need updates, a later small catalog editor can manage name (VI/optional EN), category, description, image, visibility, featured order and optional verified flipbook page reference. Add pricing only if the venue will maintain it. Keep reservations and event management unchanged. An editorial selection can begin as a reviewed local dataset; a new CMS section is not required for a first demo.

## Acceptance before publishing

Venue approval for available items/images and any price/allergen claims; readable mobile filters/cards; correct flipbook targets; Vietnamese/English fallbacks; keyboard-accessible filters/detail panels; no duplicate or conflicting prices. Any old indexed URLs should be mapped deliberately if replacing the original site, rather than copying its whole hierarchy.

## Mixed individual items and image menus — clarification

Use two content types within the same /food-drinks landing page. Individual food/drink cards (for example Trà táo) open their item detail; a separate “Thực đơn & suất ăn” section presents office lunch, set menus or image-based collections as larger editorial cards. A collection opens a dedicated page showing its approved images at readable size plus confirmed service times/conditions and a booking/contact action. Do not force a menu-sheet graphic into an individual-dish card or invent structured dishes/prices from it. Future storage can distinguish item and menu_collection, while sharing image, category and visibility fields.

The homepage discovery CTA should eventually be labelled “Khám phá món ăn & đồ uống” and link to /food-drinks. A separate “Xem thực đơn đầy đủ” action on the guide opens /menu. A featured collection can link directly to its collection page. Until the guide exists, the homepage's current “Khám phá thực đơn” link remains /menu, avoiding a dead destination.
